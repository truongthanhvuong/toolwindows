CHƯƠNG I

Tổng Quan Dự Án & Product Brief

Bối cảnh, giải pháp công nghệ và tầm nhìn kiến trúc của VUONGTT Tool Pro 2026

1. Thực Trạng & Bối Cảnh

Thợ máy tính và IT Helpdesk thường phải mang theo hàng chục công cụ rời rạc (USB cứu hộ, file BAT/CMD, tool bẻ khóa trôi nổi, driver rời rạc, phần mềm benchmark nặng nề). Quy trình cài đặt và sửa lỗi Windows diễn ra thủ công, tiêu tốn 45-90 phút/máy và tiềm ẩn rủi ro mã độc.

2. Tầm Nhìn Sản Phẩm

Xây dựng hệ sinh thái tiện ích all-in-one chạy trực tiếp trên Windows hoặc môi trường cứu hộ WinPE. Tự động hóa 85% các thao tác kỹ thuật lặp lại với thời gian xử lý tính bằng giây thông qua Native Windows API, WMI, DISM và Registry Injection.

3. Ngôn Ngữ Fluent OS Utility

Giao diện Dark Mode tối ưu cho thợ kỹ thuật làm việc liên tục trong môi trường thiếu sáng. Phân cấp typography rõ ràng với font Inter và JetBrains Mono, tương phản màu sắc cao, hiệu ứng Mica/Acrylic nhẹ nhàng nhưng tiết kiệm RAM < 85MB.

CHƯƠNG IV

Yêu Cầu Phi Chức Năng (NFR), Bảo Mật & Lộ Trình Phát Triển

Độ tin cậy hệ thống, tiêu chuẩn mã hóa và roadmap nâng cấp phiên bản tương lai

Tiêu Chuẩn Hiệu Năng (NFR)
  • Thời gian khởi động ứng dụng < 1.2 giây.
  • Chiếm dụng bộ nhớ RAM < 85MB ở chế độ nền.
  • Tương thích ngược từ Windows 7 SP1 đến Windows 11 24H2.
  • Không để lại registry rác sau khi thoát ứng dụng (Zero-footprint).
An Toàn Dữ Liệu & Bảo Mật
  • Mọi thao tác can thiệp Registry đều tạo bản sao lưu .reg tự động.
  • Chữ ký số WHQL và kiểm tra mã băm SHA256 trước khi thực thi file ISO.
  • Chế độ Safe Mode Prompt cảnh báo khi thao tác xóa phân vùng ổ cứng.
  • Không gửi dữ liệu telemetry máy khách ra máy chủ bên ngoài.
Lộ Trình Roadmap (v20.5 → v21.0)
  • v20.5 (Hiện tại): Đóng gói hoàn thiện 13 phân hệ, tích hợp Winget CLI và CrystalDiskInfo SMART.
  • v20.8 (Q3/2026): Tích hợp module khôi phục phân vùng bị format nhầm & cứu dữ liệu RAW.
  • v21.0 WinPE (Q4/2026): Bản phát hành khởi động trực tiếp từ USB UEFI cứu hộ cứu nạn.
