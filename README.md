## 🚀 Hướng Dẫn Sử Dụng

### Cách 1: Chạy trực tiếp file EXE (Khuyên dùng)
Double click vào file **`VUONGTT_Toolkit.exe`**.
- File đã nhúng sẵn đặc quyền Administrator (`requireAdministrator`), Windows sẽ hiện bảng xác nhận UAC và phần mềm khởi chạy ngay lập tức.
- Không hiện cửa sổ đen console, hoạt động độc lập không cần cài đặt thêm runtime.

### Cách 2: Chạy bằng PowerShell
Mở PowerShell với quyền Administrator và chạy lệnh:
```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
.\VUONGTT_Toolkit.ps1
```

### Cách 3: Tự biên dịch lại file EXE
Khi có bất kỳ thay đổi nào trong mã nguồn giao diện XAML hoặc module chức năng, chỉ cần chạy:
```powershell
.\Build-Exe.ps1
```
Hệ thống sẽ tự động dùng trình biên dịch `csc.exe` có sẵn trong Windows để tạo lại file **`VUONGTT_Toolkit.exe`** mới nhất.
